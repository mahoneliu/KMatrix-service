# 工具与执行设计

系统采用双层执行架构，上层是工作流（Graph），下层是原子工具（Tools/Skills）。

## 1. 核心理念

*   **工作流 (Workflow)**: 负责复杂的业务逻辑编排、状态流转和长程任务管理。
*   **Skill (原子工具)**: 负责具体的单一操作（如搜索 Google、读取文件、发送邮件）。

![](/uploads/kmatrix/images/m_1c79e6e4f3a69a4e3a89e9e8f4a1c6e1_r.png)

## 2. Skill 设计

每个 Skill 都是一个独立的函数或 API 调用，具有清晰的输入输出定义。

### 2.1 结构

```json
{
  "name": "google_search",
  "description": "搜索谷歌获取信息",
  "parameters": { ... }
}
```

## 3. 执行流程

1.  用户触发工作流。
2.  工作流引擎解析当前节点。
3.  如果是工具节点，则调用对应的 Skill。
4.  Skill 返回结果给工作流。
5.  工作流决定下一步动作。
