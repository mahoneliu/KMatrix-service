# Kmatrix核心功能

| **分类** | **功能项** | **功能描述** | **版本** |
| :--- | :--- | :--- | :--- |
| **基础功能** | **多模型支持** | **支持主流大模型（如 GPT-4, Claude-3, DeepSeek, 智谱 AI 等）** | 开源版 |
| **知识库管理** | **多源文档导入** | **支持 PDF, Word, Txt, Markdown, URL 爬取等** | 开源版 |
| | **向量化存储** | **基于 pgvector 的高性能向量存储与检索** | 开源版 |
| **工作流设计** | **可视化编排** | **支持拖拽式工作流节点编排 (LlmChat, ToolExecute, Retrieval)** | 开源版 |
| **应用发布** | **API 服务** | **提供 OpenAI 兼容的 API 接口** | 开源版 |
| | **Web 对话框** | **支持嵌入到第三方站点的 Web 聊天窗** | 开源版 |

# Kmatrix企业版功能 （开源版全部功能 +）

| **分类** | **功能项** | **功能描述** | **版本** |
| :--- | :--- | :--- | :--- |
| **高级检索** | **混合检索 (Hybrid)** | **结合语义检索与关键词检索，提升召回率** | 企业版 |
| | **重排序 (Rerank)** | **对召回片段进行精细化排序，提高精准度** | 企业版 |
| **文档分享与交流** | **互动、分享、交流** | **支持文档的分享、评论、协同、以及基于文档的深度互动与讨论交流** | 企业版 |
